# Christmas Letters – Modern Letter Layout

This package builds on the previous mobile-ready starter and adds the Modern & Elegant long-letter typography styles.

## What changed
- Added typography and spacing rules for the unlocked letter content only.
- Centered the letter kicker and title.
- Set readable long-form paragraph width, font size, line height, and spacing.
- Added mobile-specific heading and paragraph spacing.
- Kept the existing password landing page, per-person configuration, and button sizing unchanged.

## Files changed
- `assets/css/letters.css`

## Deploy
Replace the repository files with this package (or, for a minimal update, copy only the added CSS block at the bottom of `assets/css/letters.css`). Then commit and push.

The password gate is a simple client-side gate, not secure authentication.
